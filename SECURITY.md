# Security

## Reporting a vulnerability

Report it privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability**. Please don't open a public issue.

Say what is affected and how to reproduce it. We'll answer in the advisory.

If the problem is in Designsystemet itself (its CSS, its web components or its React components), and not in this port, report it to Digdir as described in [digdir/designsystemet's security policy](https://github.com/digdir/designsystemet/security/policy).

## Supported versions

Only the latest version, the newest commit on the `dist` branch, gets fixes.
